# JOGO - PEDRA, PEPEL E TESOURA
Meu primeiro projeto de programação em python

O jogo é programado em Python e funciona com o jogador escolhendo entre pedra, papel ou tesoura, enquanto o computador faz uma escolha aleatória. A cada rodada, é definido quem venceu e os pontos são contabilizados. O primeiro jogador a chegar a 5 pontos ganha e é declarado o campeão.
